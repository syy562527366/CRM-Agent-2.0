# 销售周报生成

## 何时使用
用户要一份「能直接发给上级」的周期性业绩总结时。触发说法包括：
出周报 / 本周业绩 / 这个月卖得怎么样 / 帮我总结一下销售情况 / 汇报材料。

单纯问「一共多少钱」「有几条线索」这种单点问题**不要**用本技能，直接回答即可。

## 执行步骤

1. **取数（必须全走工具，不许估算）**
   - `crm_sales_stats(group_by="month")` → 成交额、订单数、客单价
   - `crm_sales_stats(group_by="product")` → 卖得最好的商品
   - `crm_lead_stats(group_by="status")` → 线索漏斗
   - `crm_lead_stats(group_by="source")` → 来源分布
   - 需要「前 5 名商品」时，取返回结果按成交额降序取前 5，**不要**让工具返回全量再自己编。

2. **算派生指标（用 calculator，不要心算）**
   - 环比 =（本期 − 上期）/ 上期 × 100%
   - 成交率 = 成交线索数 / 线索总数 × 100%
   - 客单价 = 成交额 / 订单数

3. **组织输出**（严格按下面结构，不要增删小节）

```
## 本周概览
一句话结论（增长/下滑 + 幅度），再跟三个数字：成交额、订单数、客单价。

## 关键变化
2-3 条，每条都要带具体数字与对比基准（环比 / 上周 / 上月）。

## 结构拆解
| 维度 | 表现最好的 | 表现最差的 |
|---|---|---|
| 商品 | … | … |
| 来源 | … | … |

## 风险与建议
2 条以内。每条给「现象 + 一句可执行动作」，不要写「加强管理」这类空话。
```

## 硬性约束
- 所有数字必须能追溯到某次工具返回；工具没给的一律不写，也不要写「约」「大概」。
- 数据缺失（工具返回 `ok=false` 或某维度为空）时，在对应小节写「本次未取到」，不要留空也不要编。
- 全文 400 字以内。表格最多 3 行。
- 不要输出原始 JSON，也不要把工具返回的 `note` 字段照抄给用户。
